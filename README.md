# Food Packaging Visual–Content Mismatch (OFF-only)

Bu bitirme projesinde yalnızca **OpenFoodFacts** verileri kullanılarak, ambalajdaki görsel vaat ile içerik listesi arasındaki uyumsuzluk analiz edilir.

## Repo Yapısı
- `backend/`: FastAPI (OFF çekme + skor + risk)
- `ml/`: YOLO / OCR-NLP çalışmaları (sonra)
- `mobile/`: Flutter demo (sonra)
- `data/`: küçük örnekler (büyük veri repo dışı)
